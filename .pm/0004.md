# 0004 · bug — Terminal long-press shows accented chars (ķ) instead of key repeat

## Task

- Terminal long-press shows accented chars (ķ) instead of key repeat
- 2026-09-23 · Root cause: Plasma 6.7's /usr/bin/plasma-keyboard daemon implements hold-a-letter diacritics popup (data: /usr/share/plasma/keyboard/diacritics/base.json). A prior hack set diacriticsHoldThresholdMs=43200000 (12h) but never disabled it. Real switch: diacriticsPopupEnabled=false in [Keyboard] of both kwinrc and kcminputrc; removed the 12h hack. Daemon uses KConfigWatcher so it hot-reloads (no restart needed; PID unchanged). Persisted as scripts/fix-keyboard-hold.sh (idempotent, matches scripts/ pattern).
