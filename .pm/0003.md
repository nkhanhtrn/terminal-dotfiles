# 0003 · feature — Make Rg results open in a new vim tab on Enter

## Task

- Make Rg results open in a new vim tab on Enter

## Features

## Design

- 2026-09-23 · Rg now uses a custom sink* (RgOpenInTab) in its fzf spec: fzf.vim's s:wrap re-attaches a user sink* after fzf#wrap injects --expect, so the sink receives [key, results...]. Plain Enter (and any key) opens each selected result in its own vim tab and jumps to line:col. Paths are resolved with :p before any tabedit, because the vimrc's BufEnter lcd autocmd otherwise breaks relative paths of later results (verified: multi-select previously opened an empty buffer at pos 1:1). Verified full chain headlessly by stubbing fzf#run.
